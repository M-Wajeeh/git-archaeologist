GitArchaeologist Architecture & App Map

Proof of Concept Reference Guide for Devpost Learn Hackathon

1. Application Overview

GitArchaeologist is a high-contrast developer cockpit designed to audit and surface architectural debt in public Git repositories. Instead of generic line-count metrics, it quantifies technical debt through the lens of commit volatility: identifying files that change frequently across multiple authors.

  • Frontend: React 18, TypeScript, Vite, Tailwind CSS, Lucide icons, Warm Amber / Orange (Grafana / Cloudflare) light theme.
  • Backend: FastAPI (Python 3.11), Git CLI subprocess shallow cloner (--depth 50), Google Gemini API client with deterministic heuristic fallback.
  • Pre-baked Engine: Instant cached datasets for pallets/flask, tiangolo/fastapi, and expressjs/express guaranteeing zero-latency demo recordings.

3. Code Tour: The 3 Critical Locations

Stop 1: Shallow Clone & Volatility Extraction

backend/app/analyzer.py → analyze_repository()

Executes git clone --depth 50 into a sandboxed Python tempfile.TemporaryDirectory(). Parses git log --numstat to extract per-file churn, distinct author counts, and total lines, then calculates debt score: churn * (authors ** 1.2) * math.log(lines + 10).

Stop 2: AI Diagnosis & Deterministic Fallback

backend/app/ai_service.py → generate_file_diagnosis()

Calls Google Gemini API (gemini-1.5-flash) with file volatility statistics. If no API key is provided or the network fails, it immediately activates the deterministic rule-based heuristic fallback engine, ensuring the UI never crashes or hangs.

Stop 3: Interactive Inspector Drawer

frontend/src/components/InspectorDrawer.tsx → InspectorDrawer()

Sliding drawer with keyboard escape listener and backdrop blur. Renders micro-metrics (churn, authors, lines), the AI diagnosis markdown card, and recent commit touchpoints for the selected file.

4. To Change This, Start Here

  • Tweak Debt Scoring Algorithm: Edit backend/app/analyzer.py line 40 (adjust the author exponent or logarithmic scaling).
  • Customize Pre-baked Demo Repos: Add or modify JSON fixtures in backend/app/data/*.json.
  • Refine AI Diagnosis Prompts: Edit backend/app/ai_service.py lines 25-50.
  • Adjust Accent Colors: Look for orange-600 / amber-500 in frontend/src/components/*.tsx.

5. A Practice to Reuse

The Fallback Guarantee Pattern: When building agentic or AI-powered proof-of-concepts, never let an external LLM API quota or rate-limit break your product flow. By pairing the Gemini integration with a clean heuristic fallback in ai_service.py, the app delivers 100% reliable functionality whether online, offline, or demoing live on video.

How to run GitArchaeologist locally

Backend: cd backend && uvicorn app.main:app --port 8008 --reload
Frontend: cd frontend && npm run dev (open http://localhost:5173)
